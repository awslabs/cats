# Contributing Guidelines

At this time, we are not accepting contributions. If contributions are accepted
in the future, CATS is released under the [Apache-2.0 license](LICENSE) and any
code submitted will be released under that license.

Bug reports are welcome: open a
[GitHub issue](https://github.com/awslabs/cats/issues/new/choose) using the bug
report template, with account IDs, role ARNs, hostnames and credentials removed
from anything you paste.

If you discover a potential security issue in this project, please follow the
process in [SECURITY.md](SECURITY.md) rather than opening a public issue.
